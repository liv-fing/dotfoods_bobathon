# FLIGHT400 Lab · Dot Foods

This repository contains the lab materials for the Dot Foods IBM i Modernization Bobathon — a hands-on workshop where participants use IBM Bob IDE to explore, modernize, and extend a real IBM i application (FLIGHT400). Exercises cover code explanation, RPG modernization, system querying, React app generation, field expansion, SQL optimization, and automated testing.
